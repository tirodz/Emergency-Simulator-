# Security

Please do not put credentials, private device dumps, access tokens, or other sensitive information in public issues or pull requests.

## Reporting

For a vulnerability in the desktop application, bundled tools, update/package scripts, or any code that could expose data or execute an unexpected command, use GitHub's private security advisory flow for this repository.

For ordinary bugs and reproducible feature requests, open a regular issue with the smallest useful reproduction.

## Test-device reports

When sharing Android test results, remove account information, phone identifiers, IP addresses, and private log data unless they are necessary to reproduce the problem.

This project is intended for controlled testing only. Reports should clearly distinguish emulator/userdebug results from observations made on an unmodified retail device.
